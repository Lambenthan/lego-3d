# LEGO 3D

Website: https://lambenthan.github.io/lego-3d/

Interactive community model viewer with 1,819 playable model variants across 1,451 set numbers, plus the original cabin.

The static runtime is distributed as a release archive. The development project and raw CAD editing sources are not included. Original authors, source links, adaptations and applicable licenses are retained in the website attribution page and archive.

This project is independent and is not endorsed by the LEGO Group. Community steps are not official instructions or physical build certification. Application code retains MIT; CAD data uses its stated licenses; derived assembly connection/motion/work-view data is CC BY-SA 4.0.
